# 🚀 Career Readiness AI

An AI-powered web application that helps job seekers evaluate their resumes against a target job description and identify areas for improvement.

## 🌐 Live Demo

**Try the application:** https://career-readiness-ai.streamlit.app/

## 📌 Project Overview

Career Readiness AI analyzes an uploaded resume against a job description to help users understand how well their profile aligns with the target role.

The project combines Python-based development with natural language processing and machine learning techniques to support resume analysis.

## ✨ Features

- 📄 Resume PDF upload
- 🎯 Job description input
- 🤖 AI-powered resume analysis
- 🧠 Semantic text matching
- 📊 Resume and job description comparison
- 📈 Skill gap insights
- 📑 PDF report generation

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Web Framework:** Streamlit
- **NLP / AI:** Sentence Transformers
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas
- **PDF Processing:** PyMuPDF, pypdf
- **PDF Report Generation:** ReportLab
- **Version Control:** Git and GitHub
- **Deployment:** Streamlit Community Cloud

## ⚙️ How It Works

1. Upload your resume in PDF format.
2. Enter the target job description.
3. Run the resume analysis.
4. Review the matching results and skill gap insights.
5. Generate a PDF report of the analysis.

## 💻 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Kirxxba/career-readiness-ai-new.git
```

### 2. Open the project folder

```bash
cd career-readiness-ai-new
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start the application

```bash
streamlit run app.py
```

The application will open in your browser.

## 🎯 Project Goal

The goal of Career Readiness AI is to help students, fresh graduates, and job seekers understand the alignment between their resumes and target job descriptions so they can prepare more effectively for job opportunities.
